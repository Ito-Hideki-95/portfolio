# ポートフォリオの素材準備シート

このサイトを、ご自身の実績が伝わる公開版へ仕上げるための準備資料です。まずは「公開名・連絡先」と「代表的な3案件」を揃えると、内容を具体化できます。

## 代表案件：1案件につき以下を準備

3件を目安に、業務システム、AI・自動化、Web／会員サービスなどから優先度の高い案件を選びます。

```text
案件名（匿名でも可）：
業種・利用者：
依頼前に困っていたこと：
担当した範囲（個人担当とチーム担当を分ける）：
実装した主な機能：
利用技術：
期間・体制（公開可能な範囲）：
判断・工夫した点：
導入後に変わったこと：
成果の根拠（測定期間・比較条件がある場合）：
公開してよいURL：
画像ファイル名：
画像・社名・成果の掲載許可：
```

「何を作ったか」に加え、「どんな課題に、どう考えて取り組んだか」がわかると、依頼する側が自分の案件に置き換えやすくなります。数値がない場合も、事実として説明できる運用の変化があれば十分です。

## 画像

- 掲載許可済みの画面を、1案件あたり2〜3枚。
- 目安は横幅1,200〜1,600px程度。WebP、PNG、JPEGを利用できます。
- 個人情報、社内の機密値、APIキーなどは掲載前に除去します。
- 見せたい機能がわかる画面を優先します。全画面を小さく詰め込むより、管理画面や主要フローを選びます。
- 画像を `public/images/` に配置し、`src/content.mjs` の該当する `experiences` に `image: '/images/ファイル名.webp'` と説明用の `imageAlt` を設定します。
- 画像を提供できない案件は、匿名で説明できる構成図に差し替えます。現在の図はサンプルの構成イメージです。

## 信頼情報

- ランサーズのプロフィールURL（評価の出典リンクを付ける場合）。
- 顧客コメントは、提供された評価原稿から4件を掲載済みです。追加する場合は、実際の文面・案件名・評価日をご用意ください。
- 顔写真・ロゴは任意です。実物をご用意いただいてから掲載します。
- 実際の相談対応時間、稼働状況、保守方針を載せたい場合は、その条件。

## サービス原稿

受領ファイルは表題が全20サービスですが、本文は13「会員・ログイン・サブスクリプション機能」の途中まででした。

- 13の残りと14〜20の原稿。
- 特に紹介したいサービスを3つ。
- 料金を公開するか、個別見積もりにするか。
- 料金公開をする場合は、確定した金額、税の扱い、対象範囲、納期の起算条件、除外事項。

## 公開までの進め方

1. 現在のサイトで、色・文章の方向性・情報の並びを確認する。
2. 公開名と連絡先を設定する。
3. 代表案件を、画像と「課題・担当・工夫・結果」の説明に更新する。
4. サービスの優先順位と対応条件を調整する。
5. GitHubにアップロードし、Vercelでプレビューする。
6. スマートフォンで読みやすさと相談導線を確認する。
7. 本番公開し、公開URLと検索設定を更新する。

現在の問い合わせ部分は相談文を作成・コピーする機能です。送信先URLを設定すると外部の相談窓口に進めます。サイト内でメールを受信したい場合は、利用するフォームサービスまたはメール配信サービスを決めてから、送信機能を追加します。
