# 表示と編集のガイド

## ページ構成

参考サイトの「導入 → プロフィール → 経験 → 技術 → 実績 → サービス → FAQ」の流れを使い、実際のクライアントの声と問い合わせ導線を加えています。個人名は表示せず、サイト名は Development Partner です。

| ページ | 日本語 | 英語 |
| --- | --- | --- |
| トップ | `/` | `/en/` |
| プロフィール・経験・クライアントの声 | `/about/` | `/en/about/` |
| 技術 | `/skills/` | `/en/skills/` |
| 全70件の制作実績 | `/projects/` | `/en/projects/` |
| 全13サービス | `/services/` | `/en/services/` |
| FAQ | `/faq/` | `/en/faq/` |

各ページに問い合わせ先と相談文作成機能があります。日英の切り替えでは、ページ・カテゴリー・閲覧位置を引き継ぎます。

## 表現と操作

| セクション | 表現と操作 |
| --- | --- |
| 全体の背景 | マウスに反応する青・シアン・紫の流体。広い軌跡が文字や画像の背後でゆっくり渦を描き、消える |
| 導入 | 大きな紹介見出しと実際の制作画面の2カラム。掲載中の全72サイト・ページを2秒ごとに自動切り替え。前後ボタン・タッチスワイプ・一時停止と現在位置の表示に対応 |
| プロフィール | 紹介文、対応領域、半透明の「取り組み方」カード |
| 経験 | 11年の開発経験と、日付を確認できる4件のコメントを交互のタイムラインで表示。日付はコメント受領日 |
| 技術 | 分野ごとの球体ロゴと、右から左へ流れる技術ロゴ。ロゴにホバーすると回転 |
| 実績 | トップは3事例＋6サイト。全件ページは検索・カテゴリー・9件ずつの追加表示。詳細は画像と説明を並べたダイアログ |
| 業種別の実績 | 回転する球状の図形と業種別リンク。件数は実績データから計算し、選択カテゴリーの一覧へ移動 |
| クライアントの声 | 原文、実サイト画像、横スワイプ・マウスドラッグ・前後ボタン。領域にフォーカスすると左右・Home・Endキーにも対応 |
| サービス | PCは4列カード。トップは8件から追加表示、専用ページは全13件。カテゴリーで絞り込み可能 |
| FAQ | キーボードでも操作できる標準の開閉表示 |
| お問い合わせ | 相談文の作成・コピー。メールアドレスとメール送信用ボタンは表示しない |

画像ダイアログは Escape または閉じるボタンで閉じ、元のボタンへフォーカスが戻ります。スマートフォンでは画像と説明を縦に並べます。相談内容は保存・送信せず、利用者が作成した文章をコピーして利用できます。

## 配色・言語・動き

- 明るいテーマは淡いブルーが基調です。プロフィール・実績・FAQは白、クライアントの声は黒に近い背景、業種別実績は指定色 `#0162b4`、お問い合わせ・フッターは濃いネイビーです。
- 夜間テーマは背景とカードを濃くし、文字・ボタンのコントラストを調整します。初期値は端末の設定、手動選択は `portfolio-theme` に保存します。
- ヘッダーの一時停止ボタンで連続アニメーションを停止します。設定は `portfolio-motion` に保存し、端末の「動きを減らす」を優先します。画面外・非表示タブの連続アニメーションも停止します。
- 流体の背景は最初のマウス移動で起動し、低解像度のWebGL2で描画します。対応していない環境ではCanvas 2Dの柔らかい軌跡に切り替えます。最後のマウス操作から10秒後に描画を停止し、タブ非表示・画像の拡大表示・一時停止・「動きを減らす」設定でも停止します。タッチスクロールでは起動しません。
- 導入のスライドショーは次の画像を先読みし、表示中の画像・次の画像以外は遅延読み込みにします。画像へのマウスホバー、キーボードでの操作中、画面外・非表示タブ、動きの停止設定では自動切り替えを停止します。手動の前後操作は停止中も利用できます。
- 本文・技術一覧・全サービス・制作実績は静的HTMLです。JavaScriptなしでも本文と画像リンクを閲覧できます。

## 編集箇所

- データ・日本語の原文：`src/content.mjs`
- 日英の共通文言・英訳・ロゴ：`src/locales.mjs`
- 担当内容が確認できる3事例：`src/featured.mjs`
- 70件のURL・画像・紹介文・分類：`src/projects.mjs`
- ページ構成：`src/page.mjs`、実績一覧：`src/gallery.mjs`
- クライアントの声と相談フォーム：`src/sections.mjs`
- 配色・サイズ・各端末のレイアウト：`public/styles.css`
- 流体の色・動き・背景の重なり：`public/ambient.js` / `public/ambient.css`
- テーマ・メニュー・カルーセル・相談文：`public/app.js`
- 検索・カテゴリー・詳細ダイアログ：`public/gallery.js`

日英を両方更新し、`npm.cmd test` と `npm.cmd run build` を実行します。ローカルの確認には `npm.cmd run dev` を使います。公開URLは https://emoto-negitoro-portfolio.vercel.app/ です。
