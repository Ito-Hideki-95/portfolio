# 表示と編集のガイド

## 言語・テーマ

- 日本語は `/`、英語は `/en/` です。本文・サービス・FAQ・フォームをそれぞれ静的HTMLとして生成します。ヘッダーのJP / ENで切り替えると、閲覧中のセクションを引き継ぎます。
- 昼間／夜間の初期値は端末のカラーモードです。手動選択は `portfolio-theme` としてlocalStorageに保存します。保存が禁止された環境でも、そのページ内では切り替えられます。
- 背景は両モードとも水色です。昼は淡い `#e5f4fc`、夜は明るさを抑えた `#abcbdc` を基調とし、文字は濃紺で表示します。カード・相談フォームも同系色で統一しています。
- ヘッダーまたは技術一覧のボタンで動きを停止できます。設定は `portfolio-motion` に保存します。端末の「視差効果を減らす」などが有効な場合は、その設定を優先します。
- 動きを止めると、技術ロゴは一覧表示になります。画面外と非表示タブの連続アニメーションも停止します。

## セクションごとの表現

| セクション | 表現と操作 |
| --- | --- |
| トップ | CSSによる立体の回転、浮遊、半透明のパネル |
| 制作実績 | 71ページの画像と紹介文、カテゴリー・検索、6件ずつの追加表示。画像クリックで拡大、Escapeで閉じて元の位置に戻る |
| 開発経験 | スクロールでのマスク表示、ホバー時の図の変化 |
| クライアントの声 | 実サイトの画面、横スワイプ、マウスドラッグ、前後ボタン。領域にフォーカスすると左右キー・Home・Endも使用可能 |
| サービス | カテゴリーの絞り込み、ホバー時の線のアニメーション |
| 技術一覧 | 2段のロゴが右から左へ移動。ホバー時に一時停止 |
| 進め方 | スクロールで進むライン、工程ごとの段階表示 |
| 自己紹介 | 11年の経験を示す数字、半透明の読書面と回転する装飾 |
| FAQ・相談 | 開閉アニメーション、読みやすい高コントラストの入力面 |

スワイプはブラウザーの通常の横スクロールを使用し、ページの縦スクロールを置き換えません。JavaScriptが使えない場合も本文・全サービス・日英リンク・技術一覧は閲覧できます。

## 内容を更新する

日本語の評価コメント・サービス・経験は `src/content.mjs`、紹介文や英語の文章は `src/locales.mjs`、構成は `src/page.mjs` を編集します。英語のサービス・経験・評価は日本語データと同じ順序で対応しています。案件を追加する場合は両方を更新し、`npm.cmd test` と `npm.cmd run build` を実行してください。

色は `public/styles.css` 冒頭の `:root` と `[data-theme=dark]` の変数で調整します。動きは `prefers-reduced-motion` と `data-motion` の両方に対応してください。

制作実績は `src/projects.mjs` で編集します。カテゴリーは複数指定でき、件数は自動計算します。PCではカテゴリーのボタン、スマートフォンでは選択欄を表示します。JavaScriptが無効な場合も全71件を閲覧でき、画像リンクから元画像を開けます。[画像出典・更新ガイド](project-sources.md) を参照してください。

## 技術ロゴの出典

32項目、31種類のSVG（React / React Nativeは同じシンボル）を [Simple Icons](https://github.com/simple-icons/simple-icons) 16.0.0から取得しました。取得URLは `https://cdn.jsdelivr.net/npm/simple-icons@16.0.0/icons/{slug}.svg`、保存先は `public/images/stack/` です。[同梱ライセンス](licenses/simple-icons.md) を保持しています。ロゴは対応技術を識別するための表示です。

一覧の定義は `src/locales.mjs` の `stackLogos` にあります。画像を追加するときは同じフォルダにSVGを置き、名前とファイル名を定義してください。全対応技術は「対応技術をすべて見る」から閲覧できます。
