# 制作実績の実装内容整理（2026年11月17日）

所有者は全掲載サイトを自身の制作実績と申告し、公開サイトから担当作業を推定して具体化するよう依頼した。本更新では、この申告を前提に、画面・コンテンツ・選択UI・外部サービスへの導線など、公開結果に対応する制作・実装作業として表現を整理した。個別工程の独立した担当証明を取得したものではない。

公開画面の存在と個人の実装担当の帰属は区別する。担当資料がある認定証システム、バックエンド、Flash Reserve、美容室、Visual Anatomyは既存の確認済み範囲を優先した。外部予約・応募・決済へのリンクを独自の予約エンジンや決済基盤の開発とは記載しない。デザイン原案、非公開API、売上・性能成果は推測していない。非公開納品資料・元の構成図は公開成果物に含めない。

全70の掲載サイトURLと追加3つの公開先を確認対象とした。取得できないURLは下記の既存記録・保存画像を参照した。バックエンド案件は非公開のため公開URLはない。購入・予約・問い合わせの送信や、ログイン後の動作確認は行っていない。元の機能・技術分析は [公開サイト分析](project-analysis.md) と src/project-insights.mjs に保持する。
